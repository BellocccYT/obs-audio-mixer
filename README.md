# Auto Mixer für OBS

OBS-Plugin, das die Lautheit jeder Audioquelle und jeder Tonspur misst und zu laute oder zu leise Spuren automatisch ausgleicht. Alles läuft lokal, ohne Cloud und ohne KI-Dienste.

> [!NOTE]
> Das Plugin ist noch in Arbeit. Eine ausführliche Anleitung folgt.

Das Projekt basiert auf der offiziellen [obs-plugintemplate](https://github.com/obsproject/obs-plugintemplate). Lizenz: GPL-2.0-or-later, siehe [LICENSE](LICENSE).
